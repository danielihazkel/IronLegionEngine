\section{Vision}

Iron Legion Engine is a specialized 2D strategy game engine designed exclusively for creating large-scale strategy games that combine:

\begin{itemize}

    \item Grand strategy campaign gameplay

    \item Real-time tactical battles

    \item Massive armies

    \item Historical and fantasy factions

    \item Extensive modding support

\end{itemize}

The engine is not intended to support unrelated genres such as FPS games, platformers, RPGs, city builders, or general-purpose game development.

The primary design goal is:

\begin{quote}

Enable battles involving tens of thousands of individual soldiers while maintaining strategic depth, modability, and future multiplayer compatibility.

\end{quote}

\section{Architectural Principles}

\subsection{Principle 1: Everything is Data Driven}

Content must be loaded from external data definitions.

Examples:

\begin{verbatim}

Unit Definitions

Technology Trees

Buildings

Abilities

Campaign Events

\end{verbatim}

Hardcoded game content is prohibited.

\subsection{Principle 2: Intelligence Lives Above Soldiers}

Hierarchy:

\begin{verbatim}

Faction

  |

Army

  |

Regiment

  |

Soldier

\end{verbatim}

Decision-making should occur at Army and Regiment levels.

Soldiers primarily execute orders and maintain formation integrity.

\subsection{Principle 3: Deterministic Simulation}

Given identical:

\begin{itemize}

    \item Initial State

    \item Input Stream

    \item Random Seed

\end{itemize}

the simulation must always generate identical results.

\subsection{Principle 4: Simulation First}

Gameplay quality and simulation scale have priority over graphical fidelity.

\section{Success Criteria}

The project is considered successful when it can:

\begin{enumerate}

    \item Run a campaign map with multiple AI factions.

    \item Transition seamlessly into real-time battles.

    \item Simulate at least 20,000 individual soldiers with stable performance.

    \item Support historical and fantasy factions.

    \item Allow creation of new units and factions entirely through mods.

    \item Be architecturally prepared for deterministic multiplayer.

    \item Add all game content without engine code changes.

\end{enumerate}
